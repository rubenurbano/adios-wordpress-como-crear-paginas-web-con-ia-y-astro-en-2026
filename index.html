Conceptos fundamentales

Antes de tocar el teclado, entendamos qué es cada cosa. Cada término se explica con una analogía cotidiana.

1. ¿Qué es crear webs con IA y Astro?

Consiste en usar asistentes inteligentes (como Claude Code) que escriben el código por ti, sobre un framework moderno llamado Astro.

Método antiguo (WordPress): compras un kit pesado de piezas prefabricadas. Para poner una ventana arrastras un remolque gigante lleno de herramientas que casi no usas. La casa queda pesada y tarda en abrir las puertas.
Método moderno (IA + Astro): tienes un arquitecto robot ultraeficiente. Le dices en español qué quieres y levanta la estructura con los materiales más ligeros. Se edifica en minutos.

2. Los 4 conceptos técnicos clave

🛞 Astro — el chasis súper rápido

¿Qué es? Un framework para programar páginas web. Explicación sencilla: como el chasis de un coche de carreras diseñado para pesar lo mínimo. No carga cosas pesadas a menos que sean estrictamente necesarias.

🤖 Claude Code — el copiloto programador

¿Qué es? Herramienta de línea de comandos e IA desarrollada por Anthropic. Explicación sencilla: como tener un programador sénior sentado a tu lado. Le dictas en español y crea archivos, edita código y corrige errores por ti.

🔌 MCP (Model Context Protocol) — el puente de datos

¿Qué es? Un protocolo que conecta la IA con herramientas externas (Semrush, Google Search Console). Explicación sencilla: un conector enchufe-clavija que permite a la IA "hablar" con Google o Semrush antes de escribir la página.

🏷️ Schema Markup — la ficha técnica para Google

¿Qué es? Código invisible que dice a los buscadores de qué trata tu página. Analogía: como la etiqueta de una maleta en el avión; Google entiende al instante si eres restaurante, agencia o tienda.

4. SEO antiguo vs. SEO moderno

❌ SEO antiguo (antinatural):
Título: Agencia SEO Sevilla - Posicionamiento Web Sevilla
H1: Agencia SEO Sevilla porque hacemos posicionamiento en Sevilla
Por qué falla: robótico, repetitivo, Google penaliza el keyword stuffing y al usuario le da mala impresión.
✅ SEO moderno con IA:
Keyword discreta: Agencia de automatizaciones
H1 para el usuario: Tu operativa trabajando sola las 24 horas del día
Por qué funciona: satisface la keyword pero captura al humano solucionando su verdadero problema.

6. Glosario rápido

  • Astro: framework enfocado en rendimiento y HTML ultraligero.
  • Canibalización SEO: dos páginas del mismo sitio compiten por la misma keyword.
  • E-E-A-T: Experiencia, Pericia, Autoridad y Confianza (criterios de Google).
  • Hreflang: etiqueta HTML que indica el idioma de una página.
  • JSON-LD: formato para escribir Schema Markup de forma limpia.
  • MCP: protocolo para conectar IA con datos externos.
  • Responsive Design: diseño que se adapta a cualquier pantalla.
  • Sitemap: archivo XML que enumera las páginas del sitio para Google.

Procedimiento: 7 pasos para crear tu web

Sigue estos pasos en orden. Cada paso tiene un objetivo, una explicación y una sola acción principal.

Checklist previo al desarrollo
1

Configurar el entorno con Claude Code

Objetivo: que la IA tenga acceso directo a tus archivos.

  1. Accede a claude.com/download e instala la app o configura Claude Code en tu terminal.
  2. Inicia sesión en tu cuenta (plan Pro recomendado, ~15–20 €/mes).
  3. Abre tu proyecto local Astro.
Motivo: la IA necesita ver el proyecto para crear y modificar código por sí misma.
Error frecuente: usar el chat web normal y copiar/pegar código a mano. Solución: usa Claude Code dentro del proyecto.

Resultado esperado: la terminal reconoce tu carpeta y la IA está lista.

2

Investigación e ideación (meta-prompting)

Objetivo: planificar antes de generar código.

  1. Selecciona un modelo de razonamiento para esta fase.
  2. Pide a la IA que investigue tu idea y te dé sugerencias.
  3. Pide a la IA que redacte el prompt que le vas a enviar después (meta-prompting).
Motivo: la IA escribe mejores prompts para sí misma que un humano medio.

Resultado esperado: tienes un prompt bien construido listo para el paso 3.

3

Generación automática de la landing principal

Objetivo: crear la estructura, contenido, diseño y versiones multilingües.

  1. Envía el prompt de creación a Claude Code.
  2. La IA revisa páginas existentes para evitar canibalizaciones.
  3. Claude Code genera estructura, diseño responsive, idiomas (hreflang) y sitemap.
Nota: si MCP/Semrush falla, la IA seguirá creando la página con su conocimiento interno.

Resultado esperado: en ~7 minutos tienes una landing completa lista para revisar.

4

Corrección de estructura y copywriting humano

Objetivo: asegurar coherencia narrativa.

  1. Navega por la web y revisa los bloques visuales.
  2. Comprueba que no haya secciones huérfanas o sin título.
  3. Pide a la IA ajustar los encabezados necesarios.
Motivo: el ojo humano valida lo que la IA no puede: la experiencia real de lectura.

Resultado esperado: la narrativa fluye de principio a fin sin saltos confusos.

5

Optimización del Schema Markup

Objetivo: que Google entienda perfectamente tu página.

  1. Pide a Claude Code que audite los archivos JSON-LD.
  2. Verifica el nodo del servicio (ej. ProfessionalService) y sus campos.
Caso real: la IA detectó que se usaba el meta-title completo en el campo Name. Al corregir la plantilla base, arregló 40+ páginas automáticamente.

Resultado esperado: Schema validado sin errores.

6

Estrategia de enlazado interno (interlinking)

Objetivo: transmitir autoridad entre las páginas de tu web.

  1. Opción básica: pide a la IA enlazar hacia tus verticales más potentes.
  2. Opción avanzada (recomendada): conecta la IA a Search Console vía MCP y pide enlazar a las páginas con más visitas reales.

Resultado esperado: red de enlaces que refuerza tus páginas clave.

7

Alojamiento y despliegue

Objetivo: publicar la web en internet.

  1. Elige un hosting rápido (discos rápidos, RAM adecuada, buen soporte).
  2. Si vienes de WordPress, solicita la migración gratuita.
  3. Conecta el repositorio Astro y publica.
Consejo: con Astro no necesitas servidores caros. Un hosting básico/intermedio (~20 €/mes) vuela.

Resultado esperado: la web está online y carga en menos de 1,5 segundos.

1. Crear landing page completa (SEO + contenido)

Descripción: genera desde cero una landing page completa optimizada para Google, incluyendo contenido íntegro, diseño responsive, infográfico animado en la sección hero, sección FAQ basada en datos reales de Semrush vía MCP, revisión de E-E-A-T y GEO, y estrategia de interlinking e imágenes.

Cuándo usarlo: al crear una nueva landing desde cero o al rediseñar una existente que quieras posicionar en Google por una keyword competitiva.

Crea una landing para que se posicione en Google por agencia de automatizaciones, haz todo el contenido, sigue la estructura que ya hay, añade algún infográfico chulo animado de automatizaciones en la sección hero, revisa todo E-E-A-T, GEO, añade la sección de FAQ apoyándote en MCP por Semrush para saber qué están buscando los usuarios y responde las preguntas para la optimización, también del interlinking y utiliza imágenes...

2. Meta-prompting (mejorar tu propia instrucción)

Descripción: pide a la IA que redacte por ti el prompt ideal para conseguir lo que quieres, partiendo de una instrucción básica. La IA escribe mejores prompts para sí misma que un humano medio.

Cuándo usarlo: cuando tengas clara la idea pero no sepas cómo formularla técnicamente, o cuando quieras maximizar la calidad del resultado final.

Oye, hazme el prompt para pedirle a Claude Code esto: [Instrucción básica de lo que quieres hacer].

3. Investigación e ideación previa

Descripción: pide a la IA que investigue, opine y aporte ideas antes de programar nada. Sirve para validar una idea y explorar enfoques alternativos.

Cuándo usarlo: en la fase inicial de un proyecto, antes de generar código, para asegurarte de ir en la dirección correcta.

Quiero hacer esto, ¿qué opinas? Investiga, dame ideas y demás.

4. Auditoría y revisión de datos estructurados (Schema Markup)

Descripción: revisa y valida el JSON-LD y los nodos Schema de la página para asegurar que Google interpreta correctamente el tipo de negocio, servicio y contenido.

Cuándo usarlo: antes de publicar, o cuando Google Search Console reporte errores o advertencias de datos estructurados.

¿Puedes revisar el schema para ver que todo esté bien?

5. Corrección de estructura, claridad y narrativa visual

Descripción: ajusta secciones confusas o mal ordenadas que rompen la lectura, añadiendo contexto al inicio de un bloque para que el visitante entienda qué está viendo.

Cuándo usarlo: tras la generación automática, cuando detectes que un bloque (por ejemplo, tras las reseñas) no se entiende o no fluye narrativamente.

En el apartado donde dices diagnóstico..., añade algo al inicio porque si no, después de las reseñas, no se entiende qué es (si es una metodología, el roadmap o el método).

6. Estrategia de enlazado interno (Interlinking básico)

Descripción: pide a la IA que enlace tu página hacia las verticales más potentes de tu web para transmitir autoridad interna.

Cuándo usarlo: cuando quieras reforzar páginas clave de tu sitio sin depender de datos externos de tráfico.

Mete el interlinking para nutrir las verticales más potentes de mi web, por ejemplo Agencia SEO Barcelona, Agencia Google Ads o las que consideres.

7. Interlinking avanzado basado en datos reales (Search Console / MCP)

Descripción: conecta la IA a Google Search Console vía MCP, analiza las páginas con más visitas reales y las consultas que las posicionan, y genera enlaces internos orientados a reforzar esos activos.

Cuándo usarlo: cuando tengas MCP configurado, datos históricos en Search Console y quieras que el interlinking se base en rendimiento real, no en suposiciones.

Conéctate al Google Search Console, analiza cuáles son las páginas más visitadas, coge las consultas de esas palabras clave y haz un interlinking en esta página para nutrir esas páginas.

8. Reorganización estructural de secciones

Descripción: reordena bloques de la landing (FAQ, servicios, hero…) para que la estructura siga un flujo lógico de conversión: problema → solución → prueba social → resolución de dudas.

Cuándo usarlo: cuando la estructura generada no siga un orden comprensible para el usuario o coloque secciones clave en posiciones poco útiles.

Reorganiza la estructura de la landing: mueve el bloque de FAQ justo antes del pie de página y coloca la sección de servicios principales inmediatamente después de la sección hero.

Ejercicios prácticos con solución

Pon a prueba lo aprendido. Intenta resolver primero y luego despliega la solución.

Ejercicio 1 — Identificar SEO antiguo vs. moderno

Consigna: dos propuestas de titular para la web de un dentista en Madrid. ¿Cuál es la correcta y por qué?

  • Opción A: Clínica Dental Madrid - Dentista Madrid Económico
  • Opción B: Vuelve a sonreír sin miedo: Tu clínica dental de confianza en Madrid
Ver solución explicada

La Opción B es la correcta. La Opción A incurre en keyword stuffing (SEO antiguo): robótica e intrusiva. La Opción B sitúa el beneficio humano ("Vuelve a sonreír sin miedo") en primer plano mientras incluye keyword y localización de forma natural.

Ejercicio 2 — Redactar un prompt de corrección

Consigna: tu web creada con IA ha colocado la sección FAQ antes de explicar los servicios. Escribe el prompt para corregirlo.

Ver solución explicada 
Reorganiza la estructura de la landing: mueve el bloque de FAQ justo antes del pie de página y coloca la sección de servicios principales inmediatamente después de la sección hero.

Motivo: la narrativa debe guiar al usuario del problema a la solución, dejando las dudas frecuentes al final del embudo.

Ejercicio 3 — Detectar el error de Schema

Consigna: ¿qué error suele cometerse al rellenar el campo Name de un Schema de tipo ProfessionalService?

Ver solución explicada

Usar el meta-title completo como Name del servicio. Debe ser el nombre real del servicio o negocio, no el título SEO de la página.

Ejercicio 4 — Elegir el prompt correcto

Consigna: quieres saber qué buscan realmente los usuarios antes de redactar la sección FAQ. ¿Qué prompt usarías?

Ver solución explicada

Un prompt que combine contenido + MCP/Semrush. Ejemplo: el prompt 1 (creación de landing completa) o bien una variante específica: "Apóyate en MCP por Semrush para saber qué buscan los usuarios y redacta la sección FAQ respondiendo a esas preguntas."

Errores frecuentes y cómo evitarlos

Estos son los 5 fallos más habituales al empezar, más los errores que nunca debes cometer.

❌ Los 5 errores frecuentes

1. Meter demasiados prompts en cola a la vez

El error: escribir 10 instrucciones seguidas sin esperar a que la IA termine la primera.
Solución: lanza las instrucciones de una en una, revisa el resultado visual y luego continúa.

2. Hacer SEO antiguo (keyword stuffing)

El error: repetir "Agencia SEO Sevilla" en cada título e imagen.
Solución: enfoca los titulares al problema del cliente e incluye la keyword de forma sutil.

3. Gastar tokens con el modelo equivocado

El error: usar modelos de razonamiento profundo para tareas triviales de formateo.
Solución: usa modelos ligeros (Sonnet/Opus) para codificar; reserva los de razonamiento para ideación.

4. Ignorar errores en el Schema Markup

El error: creer que si la web se ve bonita, el código invisible para Google está bien.
Solución: pide siempre una revisión explícita del JSON-LD.

5. No validar la estructura visual tras las reseñas

El error: dejar bloques de texto inconexos que confunden al visitante.
Solución: revisa la web como si fueras un cliente real antes de dar el trabajo por terminado.

🚫 Errores que NUNCA debes cometer

  1. NUNCA hagas webs sobrecargadas con miles de plugins antiguos si buscas máximo rendimiento SEO.
  2. NUNCA abarrotes el texto de keywords de forma robótica.
  3. NUNCA lances 20 prompts seguidos sin revisar los cambios.
  4. NUNCA olvides revisar los datos estructurados Schema en JSON-LD.

💡 Trucos de profesionales

  • Dictado por voz: usa el dictado de tu sistema para explicar a la IA lo que quieres como si hablaras con un compañero.
  • Herramientas internas: pide a Claude Code que cree paneles internos para gestionar clientes, automatizar correos con Apollo o herramientas de SEO local.
